# Проектная работа: «Посмотри в окно»

Одностраничное приложение, которое позволяет пользователям смотреть видео из разных городов в разное время суток

## Описание проекта

В проекте реализован готовый интерактивный интерфейс

**Основные возможности приложения:**

- Загрузка и отображение карточек с видео.
- Возможность подгружать дополнительные карточки по кнопке «Показать ещё».
- Переключение основного видеоплеера при клике на карточку.
- Поиск видео по названию города и времени суток.
- Отображение состояния загрузки (прелоадеров) и блока с ошибкой при неудачном запросе.
